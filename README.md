# neon-glass-calculator

A simple and modern calculator built with HTML, CSS, and JavaScript. This project features a clean neon glassmorphism design and performs basic arithmetic operations with a smooth user experience.

## Features

- Basic arithmetic calculations
- Modern glassmorphism UI
- Responsive design
- Smooth button interactions
- Clean and easy-to-use interface

## Built With

- HTML5
- CSS3
- JavaScript
